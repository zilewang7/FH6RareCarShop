FH6 意大利奇珍库存控制器
版本 1.0.4  |  Windows x64  |  已测试 Xbox 应用版与 Steam 版

活动状态
========
“意大利奇珍”活动已于 2026-07-23 22:30（UTC+8）结束。本工具开源时活动已经下线，
除非活动未来返场，否则游戏内没有可供现成工具操作的对应场地。源码仍可作为其它类似
限时活动工具的参考实现与开发基座。

用途
====
在“意大利奇珍”活动场地内选择三个展位展示的车辆，并为已经购买后购买入口消失
（可能同时没有车辆模型）的车辆尝试恢复重购交互。

与随机刷新的关系
================
工具不修改存档、车库、货币或网络请求。普通切换与重购刷新调用游戏自身的展位逻辑，
候选车辆仍来自活动原有车池。从现有日志能够观察到的结果看，游戏只是正好“随机”到
所选车辆；最终效果与完全退出游戏、重新进入并等待随机命中相同，只是节省了时间。

截至已验证的游戏版本，Playground Games 未为 FH6 部署独立反作弊程序，测试中也未
观察到反作弊拦截。这不代表官方授权、永久兼容或零风险。

使用步骤
========
1. 启动 Forza Horizon 6，进入“意大利奇珍”活动场地，等待三个车辆模型完全出现。
2. 以管理员身份运行 FH6ItalianRarities.exe。
3. 可按原名、中文译名、品牌、年份、库存 ID 或车型 ID 搜索。
4. 每个展位选择一辆车后，使用“应用此展位”或“应用三个展位”。
5. 普通切换完成后，回到游戏查看车辆。

恢复重购
========
仅在目标车已经购买、购买入口消失时使用。若车辆模型也同时消失，可直接执行恢复，
无需先手动“应用此展位”：

1. 在对应展位选择刚买过的目标车，点击“恢复重购”。
2. 确认后立即切回游戏，停留在活动场地。
3. 工具会只检查目标展位；若交互已经卸载，会先自动切换临时车辆并等待重新加载。
4. 随后工具会恢复资格、调用游戏完整刷新，再切回目标车。
5. 等待工具显示完成后，在场地内确认购买入口。

完整刷新依赖游戏线程；等待期间不要强制关闭工具。若退出游戏，所有进程内临时状态
会随游戏进程一起清除。

兼容与安全检查
==============
- 工具不修改存档文件，不抓取网络流量。
- 普通切换调用游戏自己的展位 setter。
- 重购只在管理器、14 车池、车型映射、函数特征、资格 getter 全部通过校验后写入。
- 空展位或已卸载的其他展位不会阻断当前目标展位的重购操作。
- 目标展位的模型和入口同时消失时，工具会自动用中转车辆重建交互。
- 临时车池和资格写入采用事务式回滚；游戏线程状态未知时不会执行可能造成崩溃的强制回滚。
- 游戏更新后若代码特征不再唯一匹配，工具会停用对应写入功能。
- “只读扫描”不会修改游戏内存，可先在诊断页确认兼容状态。

已知验证范围
============
- 当前 Xbox 应用版与 Steam 版的三个展位切换已实测。
- Steam 6.403.798.0 已适配快速展位定位与购买资格状态解析。
- 重购链路已在 Xbox 应用版 Abarth 595 esseesse、Steam 版 Aventador LP700-4 上完成
  “实际购买 -> 入口消失 -> 恢复资格 -> 临时换车 -> 完整刷新 -> 切回目标车”的实测。
  每次游戏更新后，建议先用便宜车辆复测。
- 游戏失去焦点会打开暂停界面；完整刷新等待时仍应切回游戏。

日志与排错
==========
日志目录：%LOCALAPPDATA%\FH6ItalianRarities\Logs

常见状态：
- “等待 Forza Horizon 6”：先启动游戏。
- “无法安全识别三个活动展位”：进入活动场地并等待三个模型加载完成。
- “目标展位交互尚未加载”：立即切回游戏并停留在活动场地，等待模型重新出现。
- “未通过特征校验”：当前游戏版本已变化，工具会拒绝写入；请保留日志用于适配。
- 等待完整刷新时间较长：切回游戏并保持在活动场地，不要停留在桌面。

部分安全软件可能将其归类为修改器；请只从可信来源获取，不要盲目关闭系统防护。
