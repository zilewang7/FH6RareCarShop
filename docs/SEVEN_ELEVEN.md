# 7-Eleven 联动适配记录

版本：2.1.0-preview.1。验证日期：2026-10-08。运行时渠道 / 版本：Steam 6.461.691.0。

## 使用

解压 `win-x64.zip`，以管理员身份运行 `FH6RareCarShop.exe`。本版自带 .NET 运行时，无需另装 SDK。

1. 游戏进入南岸区 7-Eleven 店后改装车展位，等待车辆与交互加载。
2. 工具默认选择“7-Eleven 联动奇珍”和 Mazda Furai，可先在诊断页执行“只读扫描”。
3. 选择同展位目录中的车辆，点击“应用此展位”，回到游戏检查车辆。
4. 只有买过目标车后购买入口消失时才使用“恢复重购”；操作时切回游戏并停留在活动场地。

活动首次时间为 2026-10-08 14:30 UTC 至 2026-11-05 14:30 UTC；程序显示 UTC+8。是否开放以游戏内为准，日期不会绕过活动校验。

## 已完成的验证

- 使用者实机反馈（2026-10-08）：已在当前 Steam 6.461.691.0 游戏中完成“购买 → 恢复重购 → 再次购买”闭环。测试车型未记录；此项为使用者报告，与下列工具侧检查区分记录。
- 完整私有可写区域只读探测得到唯一匹配管理器，当前车为库存 242 / 车型 2363（Ford GT）。
- 生产 `ForzaGameService.InspectAsync` 正确识别单展位、14 车池、当前车和版本。
- 双 vtable RVA：`0x6B0EAE8` / `0x6B0EC38`。
- setter 特征唯一命中 `0x25B3D00`；refresh 特征唯一命中 `0x25B1F80`。保留旧版本特征回退与唯一性校验，不以猜测的新地址替代检测。
- 新版生产购买资格解析器通过只读验证：manager `+0x10` 指向 owner 实体，owner 的 `+0x08/+0x10/+0x18` 是组件集合边界，集合成员为组件的第二基类指针（组件 `+8`）。要求 manager、唯一 SaveState 及资格对象同时属于此实体；旧版固定邻近偏移不用于本版。
- owner / SaveState 双表 / 资格双表 RVA：`0x6E18D18` / `0x6B0F1D8,0x6B0F328` / `0x6DB01A8,0x6DB0310`。`SeeItDriveIt` 标记、getter `0F B6 41 70 C3`、布尔值均验证通过。独立只读探针在当前 44 个管理器上核对了相同所属实体关系。
- 离线自检：78 条目录记录，1,026 组同池中转计划，7 个回滚边界用例，24 个车池用例（正序、倒序、重复 ID、池外 ID）。
- 界面回归：1 → 2 → 3 → 1 展位切换，54 项默认选车、视图、隐藏列、诊断项与合成快照断言通过；离屏渲染未调用游戏。
- 写入前重新解析并确认原 owner / SaveState / 资格对象身份；新版本资格回滚同样验证原绑定，避免交互重建后仅凭旧地址恢复字节。对象改变时停止对应操作。
- `tests/FH6RareCarShop.OwnerTests` 的 36 项集成测试通过：5 项合法关联接受，31 项非法或过期关联拒绝；测试仅对测试进程自有模拟内存进行操作，不打开游戏。
- Release 编译启用 warnings-as-errors。

## 验证边界

本版是可运行的适配预览。资源、运行时只读验证及自动化检查已通过，使用者另行确认重购购买闭环成功。尚未覆盖 Xbox 本次更新、所有 14 辆车逐一购买或所有交互卸载场景。资格标记与 getter 的只读检查本身不等于购买闭环完成。结构不一致或关联不唯一时仍会拒绝对应操作。

不附带游戏资产、存档、内存转储或个人路径日志。
