# Security and privacy

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for issues that could cause unsafe memory writes,
arbitrary code execution, credential exposure, or unintended modification outside the game process.
Do not publish a proof of concept containing private user data before the issue is resolved.

## Diagnostic logs

Logs may contain game versions, process IDs, runtime addresses and scan statistics. Before attaching a
log to a public issue, verify that it does not contain a Windows user name, a private installation path,
an access token, a save file, or unrelated system information.

Never upload game binaries, save files, process dumps or raw memory captures to this repository.
